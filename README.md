# Обучение алгоритмам

[![Infostart](https://infostart.ru/bitrix/templates/sandbox_empty/assets/tpl/abo/img/logo.svg)](https://infostart.ru/1c/articles/2846370/)

**Публикация на Infostart:** [Обучение алгоритмам](https://infostart.ru/1c/articles/2846370/)

Учебная внешняя обработка для **1С:Предприятие 8.5**: коллекция из **70 алгоритмов** — от линейного поиска и сортировок до графовых алгоритмов, динамического программирования и структур данных. Для каждого алгоритма есть описание (сложность, область применения, типичные ошибки) и готовый пример реализации на встроенном языке, подсвеченный как код прямо в форме.

Проект ведётся в 1C:EDT как проект внешних объектов (`V8ExternalObjectsNature`).

## Возможности

| Что | Как реализовано |
|---|---|
| Список алгоритмов | таблица формы `ТаблицаАлгоритмов` с колонками «Номер», «Алгоритм» и строкой поиска |
| Описание | поле «Описание алгоритма»: суть, сложность по времени и памяти, где применять, типичные ошибки |
| Пример кода | поле HTML-документа `ПолеКодаHTML` (тип `HTMLDocumentField`) |
| Подсветка синтаксиса | собственный разбор строки на сервере: ключевые слова, строковые литералы, комментарии, директивы компиляции (`&НаСервере`, `&НаКлиенте`), числа; результат — экранированный HTML |
| Навигация | при активизации строки таблицы описание и код выбранного алгоритма сразу обновляются |

Подсветка не использует внешних компонент и сторонних библиотек: модуль формы сам разбирает текст (`РазметитьСтрокуКода`) и собирает HTML (`СформироватьРазметкуКода`, `ОбернутьHTML`, `ЭкранироватьHTML`).

## Требования

- платформа **1С:Предприятие 8.5.1** (в `DT-INF/PROJECT.PMF`: `Runtime-Version: 8.5.1`);
- для разработки — **1C:EDT 2026.1** и новее;
- язык проекта — русский.

## Запуск

1. Собрать внешнюю обработку (`.epf`) средствами EDT.
2. В 1С:Предприятие: **Файл → Открыть** → выбрать собранный `.epf`.
3. Выбрать алгоритм в списке слева — справа появятся описание и подсвеченный пример кода.

Исходники можно открыть и без сборки: в EDT проект импортируется как проект внешних объектов.

## Структура репозитория

```
Алгоритмы/                                   корень git-репозитория
└── Алгоритмы/                               проект EDT
    ├── DT-INF/PROJECT.PMF                   манифест проекта (версия платформы, язык)
    ├── .project                             описание проекта EDT
    └── src/ExternalDataProcessors/
        └── ОбучениеАлгоритмам/
            ├── ОбучениеАлгоритмам.mdo      метаданные внешней обработки
            └── Forms/Форма/
                ├── Form.form               форма: таблица, описание, поле HTML
                └── Module.bsl              модуль формы, ~3 100 строк
```

### Карта модуля формы

| Область | Содержимое |
|---|---|
| `ОбработчикиСобытийФормы` | `ПриСозданииНаСервере`, `ПриОткрытии` |
| `ОбработчикиСобытийЭлементовТаблицыФормыТаблицаАлгоритмов` | `ТаблицаАлгоритмовПриАктивизацииСтроки` |
| `СлужебныеПроцедурыИФункции` | `НаборАлгоритмов` (данные), `ЗаполнитьСписокАлгоритмов`, `ОбновитьПоляАлгоритма`, `СформироватьРазметкуКода`, `РазметитьСтрокуКода`, `ОбернутьHTML`, `ЭкранироватьHTML`, `ЭтоБуква`, `ЭтоЦифра` |

## Как добавить алгоритм

1. Написать реализацию в области `СлужебныеПроцедурыИФункции` модуля формы (для кода, который только демонстрируется, достаточно функции с директивой `&НаСервере`).
2. Добавить элемент в конец `НаборАлгоритмов()`:

```bsl
Элемент = Новый Структура;
Элемент.Вставить("Алгоритм", "Название алгоритма");
Элемент.Вставить("Описание", "Суть, сложность O(...), где применять, типичные ошибки.");
Элемент.Вставить("ПримерРеализации", "&НаСервере" + Символы.ПС +
	"Функция МояФункция(Параметр)" + Символы.ПС +
	"	Возврат Параметр;" + Символы.ПС +
	"КонецФункции");
Результат.Добавить(Элемент);
```

3. Ничего больше менять не нужно: список, нумерация и подсветка кода строятся автоматически по этому набору.
